# Функции и их параметры. Рекурсия

Решения заданий лежат в отдельных папках:

- `task1/main.cpp` — задание 1, арифметические функции.
- `task2/main.cpp` — задание 2, устранение дублирования.
- `task3/` — место для задания 3.

Чтобы запустить первое задание из папки проекта:

```powershell
g++ task1/main.cpp -o task1/main.exe
.\task1\main.exe
```

Если `g++` не находится в уже открытом терминале, закрой терминал в VS Code и создай новый.

Также можно открыть нужный `main.cpp` и нажать `Ctrl + Shift + B`.
